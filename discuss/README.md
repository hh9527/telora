# Telora design discussions

This directory holds design explorations that are not yet RFCs.

A discussion document records a user-initiated idea before a decision to pursue
it as an RFC. It may establish motivation, compare semantic models, and record
provisional syntax, but it does not commit Telora to an interface or an
implementation. Reports, audits, and experiment summaries do not belong in
this directory.

Once the important alternatives and consequences are understood and the idea
is selected for implementation, the accepted design can move into a numbered
RFC with explicit goals, non-goals, acceptance criteria, and an implementation
plan.
