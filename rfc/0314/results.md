ic-model 初始化中位数从约 65.89 秒降至 59.97 秒（约 9.0%），fuel 下降约 10.0%。
结束时存活 payload 减少约 5.3%，但 Guest 峰值保持 24.44 MiB；此版本没有证明
ic-model 初始化的线性内存配额可以大幅降低。Raw 迁入 word arena 后，committed
和累计分配包含原先独立的内容存储，不宜将两版差值直接解释为全部内存变化。

Empty / Single 微基准累计分配分别降低约 93.2% / 91.7%，但墙钟只小幅改善：
谓词调用和来源/根处理仍然存在。全命中过滤累计分配约增 90.3%，GC 从 69 增至 132，
墙钟回退约 13.4%；调查与缓冲容量求和见 validation.md。String 密集样本 fuel 增约
8.7%，Guest 峰值下降约 10.3%，存活 payload 增约 8.9%；独立 Raw 的头和管理成本
与稳定回收收益并存。这些局部回退是本实现待合入评审的已知成本，不能声称普遍加速。

所有候选功能计数来自未插桩制品。频率插桩单独运行，其耗时不进入此表。
同组各轮 fuel、Guest、payload、committed、累计分配和 GC 次数完全相同。

## 动态发布频率

在隔离源码副本中应用 [publication-profile.patch](publication-profile.patch)，扩展三个
Wasm 计数 global，只统计统一 `array_payload` 发布路径。初始化期间观察到：

| 长度 | 动态发布次数 | 该路径内占比 |
| --- | --- | --- |
| 0 | 111,941 | 39.3% |
| 1 | 105,685 | 37.1% |
| ≥2 | 66,984 | 23.5% |

这批发布中空／单元素合计 76.5%，说明特化确实覆盖大量
临时小集合。它不是整个程序的唯一对象数或全部 Array 生产频率：Host 输入、
复用已有视图的路径、直接生产 Slice 的 Dict 列投影及内部 Raw Dict 列不进入计数。
不能以此比例推导全部分配节省。原始计数和范围见
[publication-profile.json](publication-profile.json)。

插桩样本的累计分配 134,472,073 和 GC 197 次与未插桩候选完全一致；其运行时间
不进入三轮性能数据。最终实现和候选编译器不包含这些统计 global。
